# 去齿音插件参数迁移对照表

把您在其他去齿音插件上的设置换算到 HanChi 汉齿。表中数值为**通用经验起点**（根据民间信息与常见插件文档归纳），请以实际听感微调。

## FabFilter Pro-DS

| Pro-DS 参数 | HanChi 对应 | 换算建议 |
|---|---|---|
| Range（最大削减量） | 强度 | Range 6 dB ≈ 强度 55%；10 dB ≈ 强度 80% |
| Threshold | 低区/高区阈值 | 直接取相同 dB 值 |
| Frequency（Split 模式分频点） | 低区分频频率 | 5-6 kHz 起步 |
| Wide Band / Split mode | 处理模式 | 一一对应（宽带/分频段） |
| Lookahead | 前瞻 Lookahead | 直接取相同 ms 值 |
| High Quality（线性相位） | 超采样 2x-4x | 用超采样近似高频质量提升 |

## Waves DeEsser

| DeEsser 参数 | HanChi 对应 | 换算建议 |
|---|---|---|
| Thresh | 低区阈值（Split）/ 低区阈值（宽带） | 直接取相同 dB 值 |
| Freq（分频点，男 5k / 女 6k 起） | 低区分频频率 | 男声 5000-6000，女声 6000-7000 |
| Range | 强度 | Range 8 dB ≈ 强度 70% |

## iZotope RX / Nectar De-ess

| RX/Nectar 参数 | HanChi 对应 | 换算建议 |
|---|---|---|
| Cutoff（分频频率） | 低区分频频率 | 直接换算 |
| Reduction（削减深度） | 强度 | Reduction 百分比 ≈ 强度 |
| Sensitivity/Threshold | 低区阈值 | 取相同 dB 值 |

## TDR Nova（动态 EQ 当 DeEsser 用）

| Nova 参数 | HanChi 对应 | 换算建议 |
|---|---|---|
| Band 频率（4-9k 峰） | 低区分频频率 | 峰值频率作为分频中心 |
| Threshold | 低区阈值 | 直接取相同 dB 值 |
| Ratio | 压缩比（每段独立） | 直接取相同压缩比；HanChi v1.3 起每个频段可单独设 1.5:1 - 20:1 |
| Threshold Offset / lookahead | 前瞻 Lookahead | 直接取相同 ms 值 |

## 使用方法

1. 在原插件上读出您惯用的参数
2. 按上表换算到 HanChi 对应参数
3. 选「存为模板」保存成您自己的模板（存于 `%APPDATA%\HanChi\Templates\`）
4. 也可以把原插件设置截图发来，直接生成模板 XML
